# The Odin Project - Project Homepage
A simple Portfoldio homepage for some of the projects that I would have completed as part of the odin project the homepage  also makes use of media queries for desktop, tablet and mobile viewership, and also applies accessibility best practices for users that utilze screen readers.


## Built With

- **Vanilla JavaScript (ES6 modules)** — the app uses modules throughout
- **Webpack** — for bundling modules, styles, and HTML templates.
- **CSS** — custom styling


## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) and npm installed on your machine.

### Installation

```bash
# Clone the repository
git clone https://github.com/Septerm/top-homepage.git

# Navigate into the project
cd top-homepage

# Install dependencies
npm install
```

### Running the Development Server

```bash
npm run dev
```

This starts the Webpack dev server and serves the app locally (usually at `http://localhost:8080`), with live reloading as you edit.

### Building for Production

```bash
npm run build
```

This produces an optimized bundle in the `dist/` directory.

### Deploying to GitHub Pages

The app is deployed to GitHub Pages via a subtree push of the `dist` folder:

```bash
npm run deploy
```
